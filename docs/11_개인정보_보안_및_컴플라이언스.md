# CARELINK — 개인정보 · 보안 · 컴플라이언스

> 이 사업은 **민감정보와 국외이전이 동시에 걸리는 드문 조합**입니다.
> 후보자의 건강·범죄경력·체류자격을 다루면서, 해외 파트너와 정보를 주고받습니다.
> 리크루팅 착수 전에 정리해야 하는 사항을 정리했습니다.

---

## 0. 왜 지금인가

```
현지 파트너에게 후보자 정보를 보내는 순간  →  개인정보 국외이전
범죄경력·건강진단서를 수집하는 순간        →  민감정보 처리
간병 서비스 기록을 남기는 순간             →  환자 건강정보 인접
```

**세 가지가 전부 리크루팅 1기 착수와 동시에 발생합니다.** 나중에 정리하면 이미 위반 상태입니다.

---

## 1. 처리하는 개인정보 분류

### 1.1 일반 개인정보

| 항목 | 대상 | 보유 근거 |
|---|---|---|
| 성명·생년월일·연락처 | 후보자·간병사·보호자·기관담당자 | 계약 이행 |
| 주소·거주지역 | 후보자·간병사 | 계약 이행 |
| 학력·경력 | 후보자 | 계약 이행 |
| 계좌정보 | 간병사·후보자 | 급여·정산 |

### 1.2 민감정보 — 별도 동의 필수

| 항목 | 왜 민감한가 | 최소화 원칙 |
|---|---|---|
| **건강진단서** | 건강정보 | 판정 결과(적합/부적합)만 저장, 상세 소견은 보관하지 않음 |
| **범죄경력 회보서** | 범죄경력정보 | **결과값(해당 없음/있음)만 저장, 원본 파일은 확인 후 파기** |
| 국적·체류자격 | 민감정보 준함 | ADMIN 전용. 기관에는 '취업 가능 여부'로 치환 |
| 환자 상태·필요 지원 | 건강정보 인접 | 정형 항목만. 진단명·병력 수집 금지 |

> **범죄경력 원본을 서버에 쌓지 마세요.** 확인 → 결과 기록 → 원본 파기가 원칙입니다.
> 유출 시 피해 규모가 다른 항목과 비교되지 않습니다.

### 1.3 고유식별정보

외국인등록번호·여권번호는 **암호화 저장 필수**이며, 조회 시 전량 `audit_logs`에 적재합니다.

## 2. 국외이전 — 가장 큰 미설계 영역

### 2.1 언제 발생하는가

| 시나리오 | 이전 방향 | 세그먼트 |
|---|---|---|
| 현지 모집 파트너가 후보자 명단을 CARELINK에 전달 | 해외 → 국내 | E · F |
| CARELINK가 선발 결과·교육 진도를 현지 파트너에 회신 | **국내 → 해외** | E · F |
| 현지 어학기관이 학습 이력을 전송 | 해외 → 국내 | E · F |
| 클라우드 리전이 국외에 있는 경우 | 국내 → 해외 | 전체 |

**두 번째가 핵심입니다.** 선발 탈락 사유나 교육 이탈 사유를 현지 파트너에게 알려주는 것은 국외이전입니다.

### 2.2 필요한 조치

```
□ 국외이전에 대한 별도 동의 항목 신설
   — 이전받는 자, 국가, 이전 목적, 항목, 보유기간을 명시
   — 다른 동의와 묶어 받으면 무효

□ 현지 파트너와 개인정보 처리 위탁·이전 계약 체결
   — 재이전 금지, 목적 외 이용 금지, 파기 의무, 사고 통지 의무

□ 이전 항목 최소화
   — 이름·연락처·선발 결과까지. 건강·범죄경력은 이전 금지

□ 이전 기록 보관
   — 언제·누구에게·무엇을 보냈는지 audit_logs

□ 개인정보 처리방침에 국외이전 내역 공개
```

### 2.3 동의 코드 설계

`consent_records.consent_code`에 아래를 추가합니다.

| 코드 | 내용 | 필수 여부 |
|---|---|---|
| `TOS` | 이용약관 | 필수 |
| `PRIVACY` | 개인정보 수집·이용 | 필수 |
| **`SENSITIVE_INFO`** | 건강·범죄경력 처리 | **필수 (별도)** |
| **`OVERSEAS_TRANSFER`** | 국외이전 | **해당자 필수 (별도)** |
| `THIRD_PARTY_ORG` | 기관 제공 (면접 수락 시) | 필수 |
| `THIRD_PARTY_INSURER` | 보험사 제공 (보험 채널) | 해당자 필수 |
| `LOCATION` | 위치정보 (GPS 체크인 시) | 선택 |
| `MARKETING` | 마케팅 활용 | 선택 |

**필수 동의와 선택 동의를 한 화면에서 일괄 체크로 받으면 무효입니다.** 항목별로 분리하세요.

동의는 **버전으로 관리**합니다. 분쟁 시 "그때 어떤 문구에 동의했는가"가 유일한 방어 근거입니다.

## 3. 접근 권한 — 이미 설계된 것과 추가할 것

### 3.1 scope 매트릭스 (재확인)

| 필드 | ADMIN | ORG (면접 수락 후) | ORG (그 전) | CAREGIVER | PARTNER |
|---|---|---|---|---|---|
| 실명 | ○ | ○ | ✕ | ✕ | ✕ |
| 연락처 | ○ | ○ | ✕ | ✕ | ✕ |
| 국적 | ○ | ✕ | ✕ | ✕ | ✕ |
| 체류자격 코드 | ○ | ✕ (가능 여부만) | ✕ | ✕ | ✕ |
| 건강진단 결과 | ○ | 적합 여부만 | ✕ | ✕ | ✕ |
| **범죄경력 결과** | ○ | **결격 여부만** | ✕ | ✕ | ✕ |
| 경력·교육·언어 | ○ | ○ | ○ | ✕ | 본인 교육분만 |
| 계좌정보 | 정산 담당만 | ✕ | ✕ | ✕ | ✕ |

**PARTNER 열이 새로 추가됐습니다.** 교육기관·현지 파트너는 자기가 담당하는 후보자의 **교육 이력만** 봅니다.

### 3.2 환자 정보 최소 노출

간병사에게 제공되는 정보입니다.

```
✅ 병실 번호 · 필요 지원 항목 · 이동 능력 수준 · 주의사항(정형)
❌ 환자 실명 · 진단명 · 상세 병력 · 보호자 개인정보
```

`SCR-403` 화면과 API scope에서 강제합니다.

## 4. 보존 및 파기

| 데이터 | 보존기간 | 근거·비고 |
|---|---|---|
| 동의 이력 | **영구** | 분쟁 방어 |
| 근무 기록 (`service_logs`, `work_records`) | 3년+ | 임금채권 시효. 노무 검토 후 확정 |
| 급여·정산 기록 | 5년 | 세무 |
| 서류 원본 (신분·학력·경력) | 계약 종료 후 1년 | |
| **범죄경력 원본** | **확인 즉시 파기** | 결과값만 보존 |
| **건강진단서 원본** | **확인 즉시 파기** | 판정 결과만 보존 |
| 사건·사고 기록 | 5년 | 삭제 불가 |
| 탈퇴 회원 | 30일 후 파기 (분쟁 진행 시 예외) | |
| 감사 로그 | 3년 | |

**파기는 자동화되어야 합니다.** 수동 파기 정책은 지켜지지 않습니다. 배치 잡으로 처리하세요.

## 5. 보안 요구사항

| 영역 | 요구사항 |
|---|---|
| 전송 | 전 구간 TLS 1.2+ |
| 저장 | 고유식별정보·계좌정보 암호화. 나머지 민감 컬럼은 애플리케이션 레벨 암호화 |
| 파일 | presigned URL (만료 5분). 직접 URL 노출 금지 |
| 인증 | Access 15분 / Refresh 14일. 관리자는 2FA 필수 |
| 접근 통제 | 역할 기반 + 필드 단위 scope. 컨트롤러 if문 금지 |
| **감사** | 개인정보 조회·상태 변경·정산·다운로드 전량 `audit_logs` |
| 대량 조회 탐지 | 시간당 조회 임계치 초과 시 알림 |
| 백업 | 일 1회, 암호화, 별도 리전 |
| 개발 환경 | **운영 데이터 복제 금지.** 마스킹된 시드 데이터만 |

### 5.1 특히 주의할 지점

**운영 데이터를 개발 환경에 복사하는 것이 실무에서 가장 흔한 유출 경로입니다.** 개발용 시드 생성 스크립트를 처음부터 만들어 두세요. 없으면 반드시 복사합니다.

## 6. 사업 인허가 체크리스트

고용 모델에 따라 필요한 것이 다릅니다.

| 모델 | 필요 검토 |
|---|---|
| **중개(BROKERAGE)** | 유료직업소개사업 등록 (직업안정법) |
| **위탁(DELEGATION)** | 용역업 · 계약 구조 검토 |
| **직접고용 + 기관 배치** | **근로자파견 허용업무 여부 / 근로자공급사업 허가 필요 여부** |
| 교육 운영 | 요양보호사교육기관 지정 (노인복지법, 지자체) |
| 해외 인력 모집 | 현지 파견·모집 관련 인허가 (국가별 상이) |
| 결제 처리 | PG 계약. 정산 대행 시 전자금융업 해당 여부 검토 |

**세 번째가 여전히 최대 미확정 사항입니다.** `docs/04` §8 참조.

## 8. 착수 전 필수 산출물

리크루팅 1기 모집 공고 전에 준비되어야 합니다.

```
□ 개인정보 처리방침 (국외이전 내역 포함)
□ 이용약관 (후보자용 / 기관용 / 보호자용 3종)
□ 민감정보 처리 동의서 (별도)
□ 국외이전 동의서 (별도)
□ 현지 파트너 개인정보 이전 계약서
□ 교육기관 개인정보 처리 위탁 계약서
□ 근로계약서 표준안 (직접고용)
□ 기관 서비스 계약서 표준안
□ 개인정보 유출 대응 절차 (통지·신고 기한 포함)
```

**변호사 검토를 받으세요.** 특히 국외이전 동의서와 현지 파트너 계약은 표준 양식이 없어 개별 작성이 필요합니다.
