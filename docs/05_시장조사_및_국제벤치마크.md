# CARELINK — 시장조사 및 국제 벤치마크

> 국내 시장 규모·경쟁 구도와 해외 4개국 사례를 정리한 참고 자료입니다.
> 수치는 2025~2026년 공개 자료 기준이며, 정책 변화가 빠른 영역이므로 인용 전 재확인하세요.

## 2. 정책 변수 — 간병비 급여화

| 항목 | 내용 |
|---|---|
| 시행 | 2026년 하반기 |
| 1단계 | 의료중심 요양병원 약 200곳 |
| 확대 | 2028년 350곳 → 2030년 500곳 (10만 병상) |
| 본인부담률 | 100% → 30% |
| 재정 | 2026~2030년 5년간 6조 5,000억 원 |
| 대상 환자 | 약 8만 5,000명 |
| 부담 변화 | 월 200만~267만 원 → 60만~80만 원 |
| **운영 요건** | **병원 직접고용 · 3교대 원칙 · 간병인력 관리·교육 전담 간호사 배치** |

### 2.1 동시에 공급 공백이 발생합니다

- 간병인의 약 90%를 차지하는 조선족이 요양보호사 자격(320시간·4개월) 취득에 어려움
- 고령화·귀국 증가·신규 유입 감소
- H-2 신규 발급 중단 (2026.2.12)
- E-9 가사·돌봄 본사업 전환 무산, 노인 돌봄은 애초 제외
- 2026년 E-9 쿼터 8만 명 (전년 대비 −38%)

### 2.2 현장의 단가 요구

요양병원 간병은 요양원보다 업무 강도와 책임이 커 **최소 월 260~300만 원**이 필요하다는 것이 현장 주장이며, 정부가 상정하는 월 200만 원 수준으로는 인력 확보가 어렵다는 지적이 있습니다.

> **→ 급여화 수가 수준이 CARELINK 직접고용 모델의 성립 여부를 결정합니다.** `docs/10` §2.3 참조.

## 3. 국내 경쟁 구도 — 3개 층

### 3.1 1층 · 전통 소개소·협회

수익모델은 **회비**입니다. 최저임금의 4%까지 받을 수 있어 2022년 기준 월 약 7만 7,000원이며, 간병인 100명이면 회비와 부대수입으로 월 800~900만 원 수준입니다.

**이 규제된 회비 상한이 시장의 심리적 가격 천장으로 작동합니다.** 직접고용 총액 모델은 이 프레임과 비교되면 무조건 비싸 보이므로, 청구 근거를 "소개료"가 아니라 **"인력 운영 위탁"**으로 재정의해야 합니다.

### 3.2 2층 · 플랫폼

| | 케어닥 | 케어네이션 |
|---|---|---|
| 설립 | 2018 | — |
| 누적 거래액 | 3,000억 원 이상 (2025) | — |
| 운영 규모 | 월 케어코디 약 3,000명, 월 1만 명 이상 서비스 | 매칭 앱 다운로드 1위 |
| 네트워크 | 파트너 병원 160개 | 누적 증명서 38만 8,000건 |
| 투자 | 시리즈B 170억, 누적 315억 + 프리IPO 150억 | 9회 유치 |
| IPO | 한국투자증권 대표주관 (지분 투자 동시) | — |

**케어닥의 전략이 시사적입니다.** 간병 매칭에서 시작해 직접 서비스로, 다시 시니어하우징 같은 인프라로 내려가는 수직 통합 경로를 택했습니다. **매칭 수수료만으로는 해자가 안 된다고 판단한 것**이고, 이는 CARELINK의 직접고용 방향과 같은 결론입니다.

케어네이션의 **누적 증명서 38.8만 건**은 주목할 자산입니다. 증명서 발급이 곧 보험금 청구 근거이므로, 이미 보험 연계 인프라를 확보한 셈입니다.

### 3.3 3층 · 파견업

근로자파견업 허가는 상시근로자 5인 이상, 자본금 1억 원 이상, 사무실 20㎡ 이상을 요구합니다. 진입장벽이 있고, 이는 CARELINK에게 방어선이 됩니다.

## 4. 보험 채널

### 4.1 두 가지 상품 유형

| | 간병비 지원형 (사용일당) | **간병인 지원형 (지원일당)** |
|---|---|---|
| 구조 | 가입자가 직접 고용 후 청구 | **보험사가 제휴 간병인을 파견** |
| 청구 | 영수증·이체내역 증빙 | 서류 없이 간편 |
| 가족 간병 | 인정 | 불인정 |
| **공급자 필요** | ✕ | **○ ← 진입점** |

### 4.2 약관이 등록 사업자에게 유리합니다

삼성화재 약관상 간병인 정의는 **"의료기관에 소속되어 급여를 받는 자, 또는 사업자를 등록하거나 사업자 등록된 업체를 통해 간병서비스를 제공하고 고객이 비용을 지불한 것이 확인된 자"**입니다.

**"사업자 등록된 업체를 통해"가 핵심입니다.** 개인 간병인이나 무등록 알선은 보험금 지급 근거가 취약하며, 결제·근무기록·증빙을 시스템으로 남기는 사업자가 구조적으로 유리합니다.

### 4.3 단가

간병인 지원비용은 2026년 현재 평균 **145,600원/일**이 한도이며, 보험사가 간병인을 보내지 못하면 가입자가 직접 구한 비용을 한도 내에서 현금 환급받습니다.

**→ 보험사에게 공급 실패는 곧 비용입니다.** 배정 성공률을 보장할 수 있는 파트너에게 프리미엄을 지불할 유인이 있습니다.

## 5. 국제 벤치마크

### 5.1 대만 — 가장 유사하고, 우리와 같은 방향으로 이동 중

| 항목 | 내용 |
|---|---|
| 규모 | 이주노동자 85만 명 중 사회복지 분야 약 22만 명 |
| 국적 | 인도네시아 77.1%, 베트남 10.9% (2019) — 2004년 베트남 54.8%에서 역전 |
| 구조 | **가정 직접고용** → 노동기준법 미적용 |
| 문제 | 2025년 6월 조사에서 가정 이주 간병인의 65.8%만 월 1일 이상 휴무 |
| 수수료 | 이주노동자가 현지 에이전시에 월 NT$1,500~1,800 납부. 가정은 취업안정비 월 NT$2,000 |
| **전환 논의** | **장기요양 기관이 고용주가 되게 하는 방안** — 기관 고용 시 노동기준법 적용 |
| 시범 | 2025.4 파견형 시범사업. 6개 NGO, 4~24시간 단위, 월급제 최저 NT$28,590 |

**대만이 지금 가려는 방향이 CARELINK가 이미 선택한 직접고용 모델입니다.** 10년 시행착오를 건너뛸 수 있다는 뜻이자, 그 전환이 얼마나 어려운지도 보여줍니다.

### 5.2 일본 — 자격 경로 설계의 교과서

- 4개 트랙 병렬 운영: EPA / 재류자격「介護」/ 기능실습 / 특정기능
- 특정기능 개호 국적별(2023년 말): 베트남 7,937명, 인도네시아 7,411명, 필리핀 3,497명
- **개방 순서**: 방문개호는 원칙 불가였다가 2025년 4월 21일부터 요건 충족 시 허용
- SSW 전체 2026년 초 약 37만 명, 2029 회계연도까지 82만 명 목표. 베트남이 약 44%

**시설에서 먼저 열고 관리 가능성이 확인된 뒤 방문으로 확대한 순서**가 한국의 요양병원 → 재가 순서에 그대로 적용됩니다.

### 5.3 독일 — 중개 모델의 반면교사

- 동유럽 출신 24시간 상주 간병인 약 30만 명
- 폴란드 민사위탁계약(umowa zlecenie)으로 회색지대 유지. 자영업과 고용의 중간 지위
- **에이전시가 독일 가족 지불액의 약 50%를 수취**
- 2021년 6월 연방노동법원: **대기시간 포함 전체 근로시간에 법정 최저임금 적용** (5 AZR 505/20)
- DIN SPEC 33454 표준이 있으나 시장 정착 실패
- 2035년까지 35만~50만 명 돌봄 인력 부족 전망

**규제 회피형 중개 구조는 결국 판례로 붕괴하며, 붕괴 시 과거 전체 기간의 임금이 소급됩니다.** 24시간 간병을 다루는 CARELINK에게 직접적인 경고입니다.

### 5.4 미국 — 긱 플랫폼의 밸류에이션과 그 대가

| 기업 | 밸류에이션 |
|---|---|
| ShiftKey | 20억 달러 |
| Clipboard Health | 13억 달러 |
| IntelyCare | 11억 달러 |
| 상위 10개 긱 간호 플랫폼 누적 조달 | 약 14억 달러 |

그런데 **근로자 분류 재판정 시 단위 노동비용이 20~30% 증가**하며, 이것이 존재적 운영 리스크로 지목됩니다. 2026년 4월 AI Now Institute 보고서는 이들이 주 정부에 의료 인력 규제 완화를 로비하고 있으며 간호사의 임금과 보호가 약화될 수 있다고 경고합니다.

**직접고용은 이 20~30%를 처음부터 원가에 반영하고 시작하는 선택입니다.** 밸류에이션 배수는 낮게 잡히지만 규제로 사업이 뒤집힐 확률은 훨씬 낮습니다.

### 5.5 네 나라가 말하는 하나의 결론

| | 한국 | 대만 | 독일 | 미국 |
|---|---|---|---|---|
| 주 인력 | 조선족 | 인도네시아 | 폴란드 | 미국 내 긱 워커 |
| 구조 | 소개 중개 | 가정 직접고용 | 민사위탁 | 긱 플랫폼 |
| 문제 | 무자격·관리 부재 | 휴일 없음 | 대기시간 미지급 | 근로자 분류 |
| 처방 | 직접고용+3교대 | 기관 고용 전환 | 최저임금 판결 | 분류 재판정 |

**민족·제도·국가가 전부 다른데 문제와 처방이 같습니다.** 변수는 인력의 출신이 아니라 **고용 구조**입니다.

## 6. 베트남 인력 시장

| 항목 | 값 |
|---|---|
| 2026년 상반기 해외 파견 | 66,311명 (전년비 −11.2%) |
| 일본 | 28,488명 |
| 대만 | 28,205명 |
| **한국** | **3,373명** |
| 2026년 목표 | 약 112,000명 |

**한국은 베트남 인력의 주요 목적지가 아니라 일본의 8분의 1 규모입니다.** 베트남 파트너 입장에서 한국은 후순위 시장이라는 뜻이며, 협상 시 이 비대칭을 전제해야 합니다.

한편 유럽(독일·폴란드·헝가리·루마니아)이 간호·돌봄 분야에서 상승세이며, 베트남은 기술·자격 요구가 높은 시장으로 이동하는 추세입니다.
