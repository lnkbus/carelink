## 1. 세그먼트 지도 — 여섯 개의 서로 다른 사업

같은 "인력 모집"이지만 채널·메시지·리드타임·담당 조직이 전부 다릅니다. 하나의 팀으로 여섯 개를 동시에 돌릴 수 없습니다.

| # | 세그먼트 | 트랙 | 리드타임 | 3년 목표 | 채널 |
|---|---|---|---|---|---|
| **A** | 국내 동포 (F-4) | 간병사 + 요양보호사 | 즉시~5개월 | 최대 규모 | 커뮤니티·소개소·온라인 |
| **B** | 결혼이민자 (F-6) | 주간 간병·재가 | 1~5개월 | 400명 | 다문화가족지원센터 |
| **C** | 국내 고려인 (F-4) | 간병사 + 요양보호사 | 3~6개월 | 250명 | 안산·광주 커뮤니티 |
| **D** | **국내 대졸 베트남 (D-10)** | **요양보호사** | **6~12개월** | **90~330명** | **대학 취업지원팀** |
| **E** | 현지 고려인 (F-4 신규) | 간병사 + 요양보호사 | 9~15개월 | 300명 | 중앙아 현지 파트너 |
| **F** | 베트남 양성대학 (D-2) | 요양보호사 | 24~36개월 | 장기 자산 | 대학 + 광역지자체 |

### 1.1 착수 순서 — 규모가 아니라 순환 구조로 정합니다

```
0~3개월    A + B + C  국내 존재 인력  → 현금흐름 · MVP 검증 데이터
3~9개월    D          D-10 파이프라인 → E-7-2 실적 = 레퍼런스
6~15개월   E          현지 고려인     → 규모 확대
12개월~    F          양성대학        → 장기 해자
```

**D를 세 번째에 두는 이유는 규모가 아니라 레퍼런스입니다.** E-7-2 발급 실적이 나와야 지자체·대학·현지 파트너를 상대로 "우리는 실제로 배치까지 해낸다"고 말할 수 있습니다. D 없이 F(양성대학)로 바로 가면 실적 없는 신생 업체가 대학과 협상하는 구도가 됩니다.

### 1.2 세그먼트별 핵심 메시지

메시지를 잘못 잡으면 채널이 아무리 좋아도 전환이 안 됩니다.

| 세그먼트 | ❌ 통하지 않는 말 | ✅ 통하는 말 |
|---|---|---|
| A 동포 | "좋은 일자리" | "4대보험·퇴직금 있는 정규 고용, 교대 근무" |
| B 결혼이민 | "간병 일 해보세요" | "아이 학교 간 시간에, 집 근처에서" |
| C·E 고려인 | "한국에서 일하세요" | "한국어 배우면 체류기간이 3년까지 늘어납니다" |
| **D 유학생** | **"요양보호사 취업"** | **"D-10 만료 전에 정착 경로를 확보하세요"** |
| F 양성대학 | "한국 취업" | "학위 + 국가자격 + 취업 + 정착까지 한 번에" |

## 2. D-10 세그먼트 — 왜 이 풀인가

### 2.1 규모 추정

```
베트남 유학생                     106,152명 (전체의 38.9%)
  → 그중 D-2 학위과정 추정          약 74,000명
  → 연간 졸업 배출 (재학 3년 가정)   약 20,000~25,000명/년
  × 졸업 후 미취업·D-10 체류 (40%)   8,000~10,000명
  × 지방 요양시설 근무 수용 (5~10%)    400~1,000명
  × 4개월 교육 + 국가시험 감내 (50%)   200~500명
  × 국가시험 합격 (70%)                140~350명
  × CARELINK 점유 (20~40%)              30~110명/년
                                    ─────────────────
                              3년 누적  90~330명
```

**숫자가 크지 않습니다. 이 세그먼트의 값은 규모가 아니라 속도와 레퍼런스입니다.**

### 2.2 최대 장벽 — 유학생은 요양보호사를 원하지 않습니다

솔직히 짚고 가야 합니다. 한국 대학에 유학 온 베트남 학생의 희망 진로는 사무직·전문직이지 요양시설이 아닙니다. **"요양보호사 채용"으로 접근하면 전환율이 거의 0에 수렴합니다.**

### 2.3 그런데 이 지점이 열려 있습니다

D-10에는 **시한이 있습니다.** 국내 대학 졸업 + TOPIK 4급 이상 등 상위 등급은 최대 3년, 60~79점 하위 등급은 보통 1년(6개월 갱신 2회)입니다. 그리고 D-10이 끝났는데 채용이 안 되면 본국 귀국 후 재입국 경로로 갈아타야 합니다.

동시에 E-7-2는 단순 취업이 아닙니다. **E-7-2로 요양시설에서 성실히 근무하면 장기 거주 및 영주 경로로 이어질 수 있습니다.**

```
D-10 만료 임박 유학생의 선택지

  ① E-7 일반 취업     ← 경쟁 치열. 영세기업은 심사 통과 어려움
  ② 귀국 후 재입국     ← 사실상 실패
  ③ 불법체류          ← D-2 출신 불법체류자 중 베트남 69.7%
  ④ E-7-2 요양보호사  ← 자격만 따면 확실. 영주 경로 연결
```

**④를 아는 학생이 거의 없습니다.** 정보 비대칭 자체가 사업 기회입니다.

### 2.4 그래서 메시지는 이것입니다

> **"요양보호사 일자리"가 아니라 "한국 정착 경로"를 팝니다.**
>
> — D-10이 끝나기 전에 E-7-2로 전환하면 체류가 안정됩니다
> — 4개월 교육 + 국가시험으로 자격을 확보합니다
> — E-7-2 근무 실적은 장기 거주·영주 신청의 기반이 됩니다
> — CARELINK가 교육기관·취업처·비자 절차를 전부 연결합니다

### 2.5 골든 타임 — 타깃 시점

**D-10 만료 6~9개월 전**이 접촉 최적 시점입니다.

- 그보다 이르면: 아직 일반 취업에 희망을 갖고 있어 반응하지 않습니다
- 그보다 늦으면: 교육 4개월 + 시험 + 비자 심사 기간이 안 나옵니다

→ 대학 취업지원팀·국제교류처와의 협업에서 **"졸업 예정자"가 아니라 "졸업 후 6~18개월 경과자"** 명단이 핵심 타깃입니다.

## 3. 대학 접촉 경로

### 3.1 접촉 대상은 두 부서입니다

| 부서 | 보유 자원 | 원하는 것 |
|---|---|---|
| **국제교류처 / 국제처** | 유학생 명단·연락처·체류자격·졸업 현황 | 불법체류율 관리, 이탈 방지 |
| **취업지원처 / 진로센터** | 취업 통계 관리 책임 | 취업률 실적 |

**국제교류처가 데이터를 갖고 있고, 취업지원처가 실적 압박을 받습니다. 둘 다 필요합니다.**

### 3.2 대학이 움직이는 진짜 이유

이게 협상의 핵심 레버입니다.

**교육국제화역량 인증제**는 대학의 국제화 역량을 제고하고 외국인 유학생 불법체류 등 부작용을 예방하기 위해 2012년부터 매년 관계부처 합동으로 실시되고 있습니다. **2025년 평가부터 부실한 유학생 유치·관리에 대한 제재가 강화**되었고, 전문대학 별도 평가지표와 어학능력 기준 상향이 2026년부터 적용됩니다.

즉 대학에게 **유학생 불법체류율과 취업률은 인증과 직결된 생존 지표**입니다. 인증을 잃으면 비자 발급이 제한됩니다.

> **대학에 가져갈 한 문장**
> "귀 대학 베트남 졸업생 중 D-10 만료가 다가오는 학생들을 E-7-2 정규 취업으로 연결합니다. 불법체류 전환을 막고 취업 실적으로 잡힙니다. 비용은 대학이 부담하지 않습니다."

같은 모델의 선례도 있습니다. **뿌리산업 외국인 기술인력 양성대학은 13개 대학이 매년 연차평가로 유학생 교육 및 취업 실적을 평가받고, 2년 연속 D등급 이하면 선정이 취소됩니다.** 취업 연계를 대행해 줄 파트너가 대학에게 생존 문제라는 구조가 이미 검증돼 있습니다.

### 3.3 대학 선정 기준

| 우선순위 | 조건 | 이유 |
|---|---|---|
| 1 | 베트남 유학생 100명 이상 보유 | 모수 확보 |
| 2 | 전문대학 | 학위 취득 후 D-10 진입 비중 높음 |
| 3 | 보건계열 학과 보유 | 요양보호사 진입 저항 낮음 |
| 4 | **양성대학 24개교에 포함** | 이미 정책 이해도 보유, F 세그먼트로 확장 |
| 5 | 요양병원·요양시설 밀집 지역 소재 | 취업처 근접 |

**4번 교집합이 가장 효율적입니다.** 양성대학은 이미 요양보호사 교육기관 지정을 받았거나 받는 중이므로, D-10 교육까지 한 곳에서 해결됩니다.

### 3.4 접촉 순서 (4주)

```
W1  타깃 대학 20곳 선정 → 국제교류처 콜드 컨택
W2  방문 미팅 (인증제 지표 개선 관점으로 제안)
W3  취업지원처 합류 → 3자 미팅
W4  MOU 체결 목표 3~5곳 → 졸업생 대상 설명회 일정 확정
```

**MOU에 반드시 넣을 것**: 졸업생 대상 설명회 개최 권한, 학교 공식 채널(포털·메일)을 통한 안내 발송, 그리고 **성과 데이터(참여·수료·취업·이탈률)를 대학에 정기 제공하는 의무**. 마지막 항목이 대학이 인증 평가에 쓸 자료이며, 다음 기수 협상력의 원천입니다.

### 3.5 대학 외 보조 채널

| 채널 | 접근법 |
|---|---|
| 베트남 유학생 커뮤니티 (Facebook·Zalo) | 선배 사례 중심 콘텐츠. 광고보다 후기 |
| 동포·외국인 지원센터 | 지자체 운영. 상담 창구 연계 |
| 법무부 조기적응·사회통합프로그램 | 양성대학은 운영기관 선정 시 우대 |
| 기존 합격자 추천 | **가장 전환율 높음.** 추천 인센티브 설계 필수 |

## 4. 교육기관 제휴

### 4.1 D-10은 양성대학 경로가 아닙니다

혼동하기 쉬운 부분입니다.

| | 양성대학 (F 세그먼트) | 일반 교육원 (**D 세그먼트**) |
|---|---|---|
| 대상 | D-2 재학생 | **D-10 졸업자** |
| 과정 | 학위과정 내 24학점 특례 | **320시간 표준 과정** |
| 기간 | 2~3년 | **약 4개월** |
| 근거 | 2026~2027 시범사업 | 노인복지법상 요양보호사교육기관 |

**D-10은 일반 요양보호사 교육기관에서 320시간을 이수합니다.**

### 4.2 제휴 형태

| 방식 | 내용 | 적합 |
|---|---|---|
| **외국인 전용반 편성** | CARELINK가 30명 단위 모집, 교육원이 전용반 개설 | **권장** |
| 기존 반 편입 | 내국인 반에 소수 편입 | 인원 적을 때 |
| 위탁 운영 | CARELINK가 교육원 지정을 직접 취득 | 규모 확보 후 |

**전용반이 핵심인 이유**: 한국어 속도를 맞출 수 있고, 시험 대비를 집중할 수 있으며, 동기 집단이 형성돼 중도 이탈이 급감합니다. 유학생 대상 파이프라인에서 이탈률이 최대 리스크라는 점을 감안하면 여기가 가장 값싼 이탈 방지 장치입니다.

### 4.3 교육기관 선정 체크리스트

```
□ 지자체 지정 요양보호사교육기관 (노인복지법)  ← 필수
□ 행정처분 이력 없음
□ 외국인 수강 경험 보유
□ 실습처(요양시설) 연계 보유                  ← 취업처와 직결
□ 야간·주말반 운영 가능                       ← D-10은 아르바이트 병행
□ 30명 전용반 개설 의사
□ 시험 합격률 공개 가능
```

### 4.4 비용 구조 (설계 옵션)

교육비는 대체로 50~80만 원 수준입니다. 부담 주체를 정하셔야 합니다.

| 모델 | 구조 | 리스크 |
|---|---|---|
| 전액 자부담 | 학생이 부담 | 모집 저항 큼 |
| **선지원 후 상환** | CARELINK 선납 → 취업 후 급여 분할 공제 | **의무 근무 강제는 강제근로 소지 — 노무 검토 필수** |
| 기관 스폰서 | 취업 확정 시설이 부담 | 시설 부담 저항 |
| **하이브리드** | 학생 50% + 취업 시설 50%, 6개월 근속 시 학생분 환급 | **권장** |

> ⚠️ 선지원 후 상환 시 **위약금이나 의무 근무 기간을 계약으로 강제하지 마세요.** 독일·대만 사례에서 에이전시가 위약금으로 이탈을 봉쇄하다 문제가 된 지점입니다. 환급 인센티브(당근)는 되고, 위약금(채찍)은 안 됩니다.

## 5. E-7-2 적격 시설 선별

### 5.1 왜 시설 선별이 먼저인가

**E-7-2 심사는 요양보호사 자격증 외에도 고용기관 요건, 시설 적법성, 임금 수준을 함께 검토하므로 취업처 확정 단계부터 적법한 시설인지 확인하는 것이 중요합니다.**

**학생을 먼저 모으고 나중에 취업처를 찾으면 실패합니다.** 자격을 땄는데 E-7 심사를 통과할 시설이 없으면 그 학생은 이탈하고, 첫 기수 실패는 대학과의 관계를 끊습니다.

→ **시설 확보가 모집보다 먼저입니다.**

### 5.2 선별 기준

**필수 (하나라도 미달 시 제외)**

```
□ 노인복지법상 노인의료복지시설 해당       ← E-7-2 취업처 요건
□ 지자체 설치 신고·지정 정상
□ 최근 3년 행정처분·평가 미흡 이력 없음
□ 4대보험 가입 사업장
□ 내국인 근로자 5인 이상                   ← 영세 사업장은 E-7 심사 난항
□ 법무부 고시 E-7 연봉 요건 충족 의사       ← 매년 변경. 신청 시점 확인
□ 외국인 고용 제한 사유 없음 (임금체불 등)
```

**가점**

```
+ 기숙사 제공                    ← 지방 시설 정착의 결정 요인
+ 외국인 근로자 고용 경험
+ 한국어 소통 지원 인력 보유
+ 3교대 운영 (24시간 상주 아님)   ← docs/07 품질 기준
+ 요양보호사 이직률 낮음
```

### 5.3 시설 확보 목표

첫 기수 30명 기준으로 **취업처 40~50석을 미리 확보**하세요. 1.5배수입니다.

이유는 셋입니다. 시설별 채용 시점이 어긋나고, 학생의 지역 선호가 갈리며, 일부 시설이 심사 과정에서 탈락합니다.

### 5.4 시설에 제안할 내용

시설 입장에서 외국인 채용은 번거롭습니다. 그 번거로움을 전부 가져가야 팔립니다.

| 시설이 겪는 부담 | CARELINK가 대행 |
|---|---|
| E-7 서류·심사 절차를 모름 | 비자 절차 전담 |
| 채용 후 언어·문화 갈등 | 정착 지원·통역 |
| 자격·신원 검증 부담 | 클리어런스 6종 사전 완료 |
| 조기 퇴사 리스크 | 근속 관리 + 이탈 시 대체 인력 |

## 7. 시스템 반영 사항

리크루팅을 스프레드시트로 관리하면 두 번째 기수에서 무너집니다. 아래는 플랫폼에 들어간 항목입니다.

### 7.1 신규 테이블

| 테이블 | 역할 |
|---|---|
| **`partners`** | 대학·교육기관·현지 송출·지자체·간병사업자 통합 관리. 계약 상태, 담당자, 성과 |
| **`recruiting_channels`** | 세그먼트별 채널 마스터 (A~F). 트랙·비자·리드타임·목표 연결 |
| **`recruiting_campaigns`** | 캠페인 단위 (설명회, 커뮤니티 광고). 비용·지원자 수 → CAC 산출 |
| **`cohorts`** | 기수 관리 (D-10 1기 등). 단계별 목표와 실적 |
| **`cohort_members`** | 기수 × 후보자. 단계별 이탈 시점 기록 |

### 7.2 기존 테이블 변경

| 테이블 | 추가 |
|---|---|
| `candidates` | `channel_id`, `campaign_id`, `referred_by` (추천인 — 전환율 최고 채널) |
| `organizations` | `e7_sponsor_status`, `e7_reviewed_at`, `dormitory_provided`, `korean_support_staff` |
| `training_programs` | `partner_id` FK 연결 (기존에는 FK 없이 UUID만 있었음) |

### 7.3 화면

| 화면 | 내용 |
|---|---|
| **SCR-510 파트너 관리** | 대학·교육기관·시설·현지 파트너 통합. 계약 상태와 성과 지표 |
| **SCR-511 코호트 파이프라인** | 기수별 퍼널. 단계별 인원과 **이탈 시점 분석** |

### 7.4 반드시 측정할 것

```
채널별 CAC           캠페인 비용 ÷ 배치 성공 인원
단계별 이탈률        어느 단계에서 빠지는지 (선발/교육/시험/배치/근속)
추천 전환율          기존 인력 추천 → 배치 비율
시설별 근속률        어느 시설에서 오래 남는지 → 시설 선별 기준 갱신
```

**단계별 이탈 시점 기록이 가장 중요합니다.** "이탈률 20%"는 정보가 아니고, "교육 6주차에 집중 이탈"은 대응 가능한 정보입니다.
