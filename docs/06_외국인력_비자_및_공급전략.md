# CARELINK — 외국인력 비자 요건 및 공급 전략

> 트랙별로 어떤 체류자격이 취업 가능한지, 각 자격의 인력 풀 규모가 얼마인지,
> 그리고 그것이 공급 전략과 플랫폼 설계에 무엇을 요구하는지 정리한 문서입니다.
> **기준 시점: 2026년 8월.** 체류자격 제도는 자주 바뀌므로 실행 전 반드시 재확인하세요.

---

## 0. 이 문서의 결론 세 줄

1. **간병사는 해외에서 신규로 데려올 수 있는 비자가 없습니다.** 국내에 이미 정착한 외국인 풀에서만 조달됩니다.
2. **요양보호사는 유일하게 신규 유입이 열려 있는 문입니다.** D-2/D-10 → 자격 취득 → E-7-2.
3. **간병사 공급은 앞으로 줄어들 일만 남았습니다.** 그래서 "확보한 인력을 잃지 않는 것"이 곧 경쟁력이고, 이것이 직접고용 모델의 근거입니다.

---

## 1. 핵심 원칙 — 자격이 아니라 체류자격이 결정한다

간병사는 국가자격이 없는 직종입니다. 따라서 **민간 협회 자격증은 취업 가능 여부에 아무 영향을 주지 않습니다.**

```
간병사 취업 가능 여부  =  체류자격의 활동범위에 해당 업무가 포함되는가
                         (자격증 보유 여부와 무관)

요양보호사 취업 가능 여부 =  체류자격 요건  AND  국가자격 보유
```

이 차이가 두 트랙의 공급 전략을 완전히 갈라놓습니다.

## 4. F-4 단순노무 제한 — 반드시 확인할 것

F-4는 **단순노무 행위**에 취업 제한이 있습니다. 2026년 2월 12일 H-2 통합과 함께 고시가 개정되었습니다.

**개정 내용 (2026.2.12 시행)**
- 기존 제한 직업 중 건설 단순 종사원, 광업 단순 종사원, 수동 포장원, 주유원, 매장 정리원, 주차 안내원, 하역·적재 단순종사원 등 **10개 직업의 취업이 허용**됨
- 나머지 **37개 직업은 단계적 확대 예정**
- 별도로, 지역특화형 비자 사업 대상 지역에 거소를 둔 F-4는 해당 광역시·도 내에서 단순노무 제한을 적용받지 않을 수 있음

**간병 업무의 취급이 불명확합니다.** 한국표준직업분류상 간병인은 서비스 종사자로 분류되어 단순노무직(대분류 9)과 구분되며, 실무에서 F-4 동포가 간병인으로 일하고 있습니다. 다만 개정 고시의 세부 목록을 직접 확인하지 못했습니다.

> ### 🔴 실행 항목 (인력 계약 전 필수)
> 1345 또는 관할 출입국·외국인청에 아래를 **문서로** 질의하고 회신을 보관할 것.
> - ① F-4 자격자의 병원 간병 업무 종사 가능 여부 (**무자격** 상태)
> - ② F-4 자격자의 병원 간병 업무 종사 가능 여부 (**요양보호사 자격 보유** 상태)
> - ③ 지역특화형 지역 거소 F-4의 경우 위 판단이 달라지는지
>
> 구두 확인으로는 부족합니다. 이 답변이 사업 모델의 전제입니다.

## 5. 공급 구조가 축소되고 있다는 사실

간병사 공급에 동시에 세 가지가 겹쳤습니다.

| 요인 | 내용 | 영향 |
|---|---|---|
| H-2 신규 중단 | 2026.2.12부터 발급 중단 | 동포 신규 유입 경로 축소 |
| E-9 돌봄 확대 무산 | 가사관리사 시범사업 본사업 전환 중단. 노인 돌봄은 애초 제외 | 신규 유입 0 |
| E-9 쿼터 축소 | 2026년 8만 명, 전년 대비 38% 감소 | 전반적 축소 |
| 조선족 고령화 | 고령화·귀국 증가·신규 유입 감소 | 기존 풀 자연 감소 |

반면 수요는 **간병비 급여화**로 확대됩니다. 2026년 하반기 200개 요양병원 → 2028년 350곳 → 2030년 500곳(10만 병상).

```
   공급 ↓↓        수요 ↑↑
     └──────┬──────┘
            ▼
   확보한 인력을 잃지 않는 것이 곧 경쟁력
            ▼
      DIRECT_EMPLOYMENT 의 근거
```

**중개 모델은 인력을 붙잡아 둘 수단이 없습니다.** 공급이 줄어드는 시장에서는 고용 관계가 곧 자산입니다.

## 6. F-6 결혼이민자 — 저평가된 전략 자산

결혼이민자 188,105명 중 베트남 출신은 상당한 비중을 차지합니다. 이들의 특성은 다음과 같습니다.

- 취업 제한 없음 (F-6)
- 한국어·베트남어 모두 가능
- 이미 국내에 정착, 이탈 위험 없음
- 40~50대 비중이 높아 돌봄 직종 적합

**단순한 간병 인력이 아니라 파이프라인 운영의 핵심 자산입니다.**

| 역할 | 기여 |
|---|---|
| 현장 인력 | 간병·요양 직접 종사 |
| **통역·멘토** | 베트남 유학생·후배 인력의 정착 지원 |
| **현지 모집 접점** | 신뢰도 있는 리크루팅 채널 |
| **이탈률 저감** | 선배 정착자 네트워크가 이탈률을 실질적으로 낮춤 |

앞서 확인한 **D-2 불법체류자 중 베트남 비중 69.7%** 문제를 완화할 수 있는 사실상 유일한 자원입니다.

## 7. 트랙별 공급 전략 종합

```
┌─ 간병사 트랙 (병원 · 보험 채널) ────────────────────────┐
│  공급원   F-4 동포 + F-6 결혼이민 + F-2/F-5             │
│  신규유입 ✕ 불가능                                      │
│  전략     기존 풀 확보 + 이탈 방지                       │
│           직접고용 · 처우 · 경력관리 · 지역특화형 활용    │
│  고용모델 DIRECT_EMPLOYMENT (기관) / BROKERAGE (보험)   │
└─────────────────────────────────────────────────────────┘

┌─ 요양보호사 트랙 (장기요양시설) ────────────────────────┐
│  공급원   위 전부 + D-2/D-10 → E-7-2                    │
│  신규유입 ○ 유일하게 열린 문                             │
│  전략     ① 국내 대졸 외국인 (6~12개월)  ← 즉시 착수     │
│           ② 양성대학 파이프라인 (24~36개월) ← 병렬 준비  │
│  고용모델 DIRECT_EMPLOYMENT                             │
└─────────────────────────────────────────────────────────┘

┌─ 의료지원 트랙 (간호조무사) ────────────────────────────┐
│  공급원   국내 정착 외국인 + 내국인                       │
│  신규유입 △ 국가시험 리드타임 최장                        │
│  전략     자격 경로 관리에 집중, 매칭 성사는 후순위 KPI   │
└─────────────────────────────────────────────────────────┘
```

## 9. 플랫폼 설계 요구사항

이 문서의 내용은 코드에 반영되어야 합니다. 상세는 `docs/03_schema.sql`의 `visa_statuses` / `track_visa_eligibility` 참조.

### 9.1 비자 적격성 필터는 매칭의 하드 필터입니다

```
❌  매칭 결과에 비자 부적격 후보가 섞여 나옴 → 운영자가 수동으로 걸러냄 → 사고
✅  runMatching() 단계에서 track_visa_eligibility 조회 → 부적격 후보 제외
```

**비자 부적격 인력을 배치하면 불법 취업 알선이 됩니다.** 이것은 편의 기능이 아니라 컴플라이언스 게이트입니다.

### 9.2 필수 구현 항목

| 항목 | 내용 |
|---|---|
| `visa_statuses` 마스터 | 체류자격 코드, 취업제한 유형, 확인 필요 여부 |
| `track_visa_eligibility` | 트랙 × 비자 허용 매트릭스. `requires_conversion`, `requires_qualification` 플래그 |
| `candidates.visa_status_code` | 후보자 현재 체류자격 |
| `candidates.visa_expires_on` | **만료 관리 필수** — 서류 만료와 동일한 알림 잡 |
| 매칭 하드 필터 | 부적격 후보 제외 + 제외 사유 로그 |
| 만료 알림 잡 | 만료 60일/30일 전 알림. 배치 중인 인력 우선 |
| `PENDING_CONFIRMATION` 상태 | F-4 간병 등 판단이 확정되지 않은 조합은 자동 배정 차단 → 운영자 검토 큐 |

### 9.3 절대 하지 말 것

**체류자격 적격성을 시스템이 자동 판정하지 마세요.** 플랫폼은 사람이 판정한 결과를 **기록**할 뿐입니다. 특히 §4의 F-4 간병 문제처럼 회색 영역은 `PENDING_CONFIRMATION`으로 두고 운영자 확인을 강제해야 합니다.
