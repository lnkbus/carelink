# CARELINK — 품질관리 및 리스크 통제 설계

> 간병 시장의 사고·학대·업무범위 위반 리스크를 **민족이나 국적이 아니라 구조로** 통제하는 설계 문서입니다.
> 이 문서의 통제 장치는 `docs/03_schema.sql`과 와이어프레임에 반영되어 있습니다.

---

## 1. 문제 정의 — 무엇이 사고를 만드는가

### 1.1 시장의 결함 다섯 가지

| 결함 | 현재 상태 |
|---|---|
| 신원 검증 없음 | 개인 간병인은 신분·범죄경력 확인 절차가 없음 |
| 자격·교육 없음 | 국가자격도 통일된 의무교육 기준도 없이 활동 가능 |
| **책임 주체 없음** | 간병인은 법적 근거가 없는 민간 직종. 소개업체도 업무 과실에 책임지지 않음 |
| 근무 기록 없음 | 무슨 일이 있었는지 확인할 원본 기록이 존재하지 않음 |
| 업무범위 통제 없음 | 의료행위 요구를 막을 장치가 없음 |

### 1.2 근본 원인은 노동조건입니다

```
24시간 입주  +  최저임금 미달(일당 10만 원 = 시급 4천 원대)
             +  근로기준법상 '가사사용인' 적용 배제
             +  산재보험 미적용  +  휴일 없음
                          ↓
              내국인은 이 조건을 받지 않음
                          ↓
              다른 선택지가 없는 사람만 남음
                          ↓
       교육 없음 · 감독 없음 · 기록 없음 · 책임 주체 없음
                          ↓
                       사고 발생
```

**어떤 국적의 인력을 이 파이프에 넣어도 같은 결과가 나옵니다.**

### 1.3 국제 비교가 이를 증명합니다

| | 한국 | 대만 | 독일 |
|---|---|---|---|
| 주 인력 | 조선족 | 인도네시아 77% | 폴란드 등 동유럽 |
| 규모 | 약 3.5만 | 약 22만 | 약 30만 |
| 구조 | 소개소 중개, 고용주 없음 | 가정 직접고용, 노동기준법 미적용 | 민사위탁계약(회색지대) |
| 문제 | 무자격·관리 부재·학대 | 휴일 없음(65.8%만 월 1일 이상) | 에이전시 50% 수취, 이탈 봉쇄 |
| 처방 | 병원 직접고용 + 3교대 + 관리 간호사 | 기관 고용 전환 → 노동기준법 적용 | 대기시간 포함 최저임금 판결 |

**민족 구성은 전부 다른데 문제와 처방이 동일합니다.** 변수는 민족이 아니라 구조입니다.

### 1.4 그리고 조선족 공급은 사라집니다

고령화·귀국 증가·신규 유입 감소에 더해 H-2 신규 발급이 중단됐습니다. 자격 취득에 320시간·4개월이 필요해 급여화 시 상당수가 제도 밖으로 밀려납니다.

**"조선족 문제"는 대응 대상이 아니라 없어질 상수입니다.** 구조를 바꾸지 않으면 국적만 바뀌고 같은 일이 반복됩니다.

## 2. 포지셔닝 원칙 — 절대 지킬 것

> **국적을 거르는 것이 아니라 검증되지 않은 인력을 거릅니다.**
> 조선족이든 고려인이든 결혼이민자든 내국인이든, **동일한 검증·교육·기록 체계**를 통과한 사람만 배치합니다.
> 그리고 사고가 나면 CARELINK가 책임집니다.

### 2.1 이 원칙을 지켜야 하는 실무적 이유

| 이유 | 설명 |
|---|---|
| **팔리는 메시지** | 기관이 사려는 것은 "다른 국적"이 아니라 "사고가 안 나는 인력" |
| **실행 가능성** | 국적 배제 시 당장 쓸 인력의 절대다수가 사라짐. F-4는 55만 모수의 핵심 |
| **규제 리스크** | 국적 기반 채용 선별은 차별 이슈. 정부의 '출신국 차별 해소' 정책 방향과 정면 충돌 |
| **계약 리스크** | 기관 계약·정부 사업 참여에서 결격 사유가 됨 |

### 2.2 코드·문서·마케팅에서 금지

- 국적을 매칭 점수나 필터의 입력값으로 사용하지 않습니다
- `nationality` 컬럼은 통계·행정 목적에만 사용하며 매칭 로직에서 참조 금지
- 기관 노출 화면에 국적을 표시하지 않습니다 (체류자격도 '취업 가능 여부'로 치환)
- 영업 자료에 특정 국적을 부정적으로 언급하지 않습니다

**언어 능력은 국적과 다릅니다.** 간병은 의사소통이 업무의 본질이므로 **한국어 수준은 정당한 매칭 기준**입니다. 국적이 아니라 TOPIK·KIIP 등 객관 지표로 평가하세요.

## 3. 통제 장치 6가지

### 3.1 신원 검증 (Identity & Background)

배치 전 필수 확인 항목입니다.

| 항목 | 문서 유형 | 갱신 주기 |
|---|---|---|
| 신분 확인 | `IDENTITY` (여권·외국인등록증·신분증) | 체류기간 만료 시 |
| **범죄경력 확인** | `CRIMINAL_RECORD` | 2년 |
| 건강 상태 | `HEALTH` (건강진단서) | 1년 (발급 6개월 이내 제출) |
| 체류자격 | `visa_status_code` + `visa_expires_on` | 만료일 관리 |

**미검증 인력은 매칭 결과에 나오지 않습니다.** 운영자가 예외 처리할 수 없도록 시스템 레벨에서 차단합니다.

### 3.2 필수교육 이수 강제

| 과정 | 내용 | 이수 시점 |
|---|---|---|
| 감염관리 | 손위생, 격리, 개인보호구 | 배치 전 |
| 인권·존엄케어 | 학대 예방, 신체 구속 금지 | 배치 전 |
| 안전 | 낙상, 이동 보조, 응급 상황 대응 | 배치 전 |
| **업무범위** | 무엇을 하지 않는가. 요구받았을 때 어떻게 하는가 | 배치 전 |
| 보수교육 | 사례 기반 | 연 1회 |

**업무범위 교육이 가장 중요합니다.** 대부분의 사고는 간병인이 "해달라고 해서" 의료행위를 한 데서 시작합니다. 거절하는 방법과 신고 경로를 가르치는 것이 핵심입니다.

### 3.3 업무범위 하드 게이트

```
서비스 카탈로그 (care_service_items)
  ├─ 포함: 식사 도움 · 이동 보조 · 위생 지원 · 체위 변경 · 말벗
  └─ 제외: 투약 · 주사 · 석션 · 욕창 처치 · 혈당 측정 · 관장 등
            → 항목 자체가 존재하지 않음

자유 입력 필드 (care_requests.cautions, 상담 메시지)
  → restricted_act_keywords 사전으로 스캔
  → 감지 시 자동 배정 차단, status = OPS_REVIEW
  → 운영자가 보호자에게 설명 후 재신청 유도
```

**키워드 감지는 거부가 아니라 검토 트리거입니다.** 자동 거절하면 보호자가 표현을 바꿔 우회합니다. 사람이 개입해 설명하는 것이 목적입니다.

### 3.4 근무 기록 append-only

`service_logs`는 UPDATE·DELETE 하지 않습니다. 정정은 `correction_of`로 새 행을 추가합니다.

- 체크인/아웃은 병실 QR 기준 (GPS는 동의·법규 검토 후)
- 지원 항목 수행 기록은 정형 항목으로만 (서술형 금지 — 의료기록과 혼동 우려)
- 이 기록이 사고 조사·정산 분쟁의 **유일한 근거**입니다

### 3.5 사건 대응 SLA

| 유형 | 1차 대응 | 에스컬레이션 |
|---|---|---|
| `SAFETY_INCIDENT` 안전사고 | **4시간** | 즉시 경영진 + 기관 통보 |
| `HARASSMENT` 부당대우·차별 | **4시간** | 별도 경로 (인력 보호) |
| `SCOPE_VIOLATION` 업무범위 초과 요구 | **4시간** | 기관·보호자 계도 |
| `WORK_HOUR_DISPUTE` 근무시간 이견 | 1일 | `service_logs` 대조 |
| `SERVICE_QUALITY` 품질 | 3일 | 재교육·재배치 |

**대응 이력은 삭제할 수 없습니다.** `audit_logs`에 전량 적재합니다.

### 3.6 교대 근무 설계 — 가장 근본적인 장치

**24시간 입주를 기본값으로 두지 않습니다.**

| 패턴 | 코드 | 1인 근무시간 | 권장도 |
|---|---|---|---|
| 8시간 3교대 | `H8_3SHIFT` | 8시간 | **권장** — 급여화 시범사업 원칙 |
| 12시간 2교대 | `H12_2SHIFT` | 12시간 | 권장 |
| 주간 전담 | `DAY` | 9~12시간 | 권장 |
| 야간 전담 | `NIGHT` | 12시간 | 조건부 |
| 24시간 상주 | `H24_LIVE_IN` | 24시간 | **비권장 · 예외 승인 필요** |

`H24_LIVE_IN`은 시스템에서 선택 가능하되 **운영자 승인 없이는 배정되지 않습니다.** 그리고 직접고용 인력에게는 근로시간 규정 검토가 완료되기 전까지 배정하지 않습니다.

> **왜 이것이 근본적인가**
> 잠을 못 자는 사람에게 품질을 요구할 수 없습니다. 24시간 입주를 유지하는 한 나머지 다섯 개 장치도 결국 무너집니다.
> 정부 시범사업의 '3교대 원칙'과 "2시간·4시간 근무 형태로 바꿔야 한다"는 정책 방향이 모두 여기를 가리킵니다.

## 4. 배치 전 클리어런스 게이트

위 장치들을 하나의 게이트로 묶습니다. **모든 항목이 PASS여야 배치 가능합니다.**

```
worker_clearances (인력 단위, 유효기간 있음)
  ├─ IDENTITY_VERIFIED       신분 확인
  ├─ CRIMINAL_RECORD_CLEAR   범죄경력 확인
  ├─ HEALTH_CHECK            건강진단
  ├─ VISA_ELIGIBLE           체류자격 적격 (외국인만)
  ├─ MANDATORY_TRAINING      필수교육 이수
  └─ SCOPE_TRAINING          업무범위 교육 이수
              ↓ 전부 PASS
        READY_FOR_DEPLOYMENT
              ↓
engagement_compliance_checks (배치 단위)
  ├─ DISPATCH_LAW_REVIEW     도급/파견 판단
  ├─ WORKING_HOURS           근로시간 규정
  ├─ SOCIAL_INSURANCE        4대보험
  └─ CONTRACT_SIGNED         계약 체결
              ↓ 전부 PASS
           ACTIVE
```

**두 게이트의 차이**: `worker_clearances`는 사람에 붙고 유효기간이 있습니다. `engagement_compliance_checks`는 배치 건에 붙고 일회성입니다.

## 5. 품질 지표 (KPI)

기존 KPI에 추가합니다. **트랙별·국적별이 아니라 검증 등급별로 봅니다.**

| 지표 | 정의 | 목표 |
|---|---|---|
| 클리어런스 완료율 | 전체 인력 중 6개 항목 전부 PASS 비율 | 95%+ |
| 클리어런스 만료 방치율 | 만료 후 미갱신 상태로 배치 중인 인력 | **0%** |
| 사건 발생률 | 서비스 1,000건당 `SAFETY_INCIDENT` 건수 | 하향 관리 |
| 4시간 SLA 준수율 | 고위험 3개 유형 | 100% |
| 업무범위 요구 감지 건수 | `SCOPE_VIOLATION` + 키워드 감지 | 추이 관찰 |
| 24시간 배정 비율 | `H24_LIVE_IN` / 전체 배정 | 하향 관리 |
| 재교육 이수율 | 사건 관련 인력의 보수교육 | 100% |

**"사건 발생률 0"을 목표로 두지 마세요.** 0으로 보고되는 조직은 보고하지 않는 조직입니다. 목표는 **감지율을 높이고 대응 시간을 줄이는 것**입니다.

## 8. 영업 메시지 (기관·보험사용)

시장에 없는 것을 판다는 점을 명확히 하세요.

> **지금 시장에서 간병인에게 사고가 나면 책임지는 곳이 없습니다.**
> 소개소는 소개만 하고, 협회는 회비만 받고, 병원은 사적 고용이라 관여하지 않습니다.
>
> CARELINK는 다릅니다.
> — 신원·범죄경력·건강·자격을 확인한 인력만 배치합니다
> — 필수교육을 이수하지 않으면 시스템이 배정을 막습니다
> — 모든 근무가 수정 불가능한 기록으로 남습니다
> — 사고가 나면 4시간 내에 대응하고, CARELINK가 책임집니다

급여화 시범 요양병원에는 이 한 줄이 추가됩니다.

> **직접고용·3교대·관리 전담 인력 요건을 병원 대신 수행합니다.**
