# CARELINK — 유닛 이코노믹스 및 재무 모델

> 직접고용 결정과 채널별 고용모델 분리를 **숫자로 검증**하는 문서입니다.
> 모든 수치는 공개 자료 기반 추정이며, 실제 계약 단가로 대체되어야 합니다.
> **이 문서의 목적은 정답을 주는 것이 아니라 어떤 값이 사업의 생사를 가르는지 드러내는 것입니다.**

## 1. 원가 구조 — 직접고용의 실제 비용

| 항목 | 금액 | 근거 |

| 4대보험 사업주 부담 (약 10%) | 260,000 ~ 300,000 | |
| 퇴직급여 충당 (8.3%) | 216,000 ~ 249,000 | |

| 교육·검증 상각 (24개월) | 30,000 | 클리어런스 6종 + 필수교육 |

| **총 원가** | **약 3,384,000 ~ 3,869,000** | |

### 1.1 가동률이 원가를 결정합니다

직접고용의 결정적 변수입니다. 배치 공백에도 급여가 나갑니다.

```
가동률 100%  → 실질 원가  3,600,000원/월
가동률  90%  → 실질 원가  4,000,000원/월  (+11%)
가동률  80%  → 실질 원가  4,500,000원/월  (+25%)
가동률  70%  → 실질 원가  5,140,000원/월  (+43%)
```

**가동률 80% 미만이면 어떤 채널에서도 마진이 나오지 않습니다.**

→ 이것이 간병과 기관 배치를 같은 인력 풀로 묶어야 하는 이유입니다. 기관 배치 공백기를 보험 간병으로 메워 가동률을 유지하는 것이 **선택이 아니라 생존 조건**입니다.

## 2. 채널별 유닛 이코노믹스

### 2.1 보험 간병 (위탁 모델)

| 항목 | 일 단위 | 비고 |
|---|---|---|
| 보험 지급 한도 | 145,600 | 2026년 평균. **매출 천장** |
| 간병사 용역대가 | 120,000 | 시장 단가 |
| **총마진** | **25,600 (17.6%)** | |
| 운영비 (배차·정산·CS) | 10,000 | |
| **순마진** | **15,600 (10.7%)** | |

**월 100명 가동 시** (인당 월 20일)
```
2,000일 × 15,600원 = 31,200,000원/월
```

**왜 직접고용이 아니라 위탁인가**
직접고용 시 인건비의 21%가 추가되어 일 약 25,000원이 붙습니다. 마진 25,600원이 거의 소멸합니다. **단가 천장이 고정된 채널에서 직접고용은 성립하지 않습니다.**

### 2.2 요양병원 1:1 배치 (직접고용)

| 항목 | 월 | 비고 |
|---|---|---|
| 기관 청구 단가 | 4,300,000 ~ 4,500,000 | 원가 + 마진 |
| 총 원가 (가동률 90%) | 4,000,000 | §1 참조 |
| **마진** | **300,000 ~ 500,000 (7~11%)** | |

**얇습니다.** 그런데 이 채널의 값은 마진이 아니라 **안정성**입니다. 상시 배치라 가동률이 95% 이상 유지되고, 그 자체가 다른 채널의 원가를 낮춥니다.

### 2.3 요양병원 공동간병 1:4 — ⚠️ 여기가 문제입니다

급여화 시범사업의 기본 구조입니다. 간병인 1명이 환자 4명을 돌봅니다.

```
환자 1인당 월 수가(총액)  ?????  ← 이 값이 사업의 생사를 가릅니다
  × 4명
  = 간병인 1명당 월 수입
  − 총 원가 4,000,000원
  = 마진
```

**손익분기 수가**

| 환자당 월 수가 | 간병인당 수입 | 마진 | 판정 |
|---|---|---|---|
| 800,000 | 3,200,000 | **−800,000** | **적자** |
| 1,000,000 | 4,000,000 | 0 | 손익분기 |
| 1,200,000 | 4,800,000 | +800,000 | 성립 |
| 1,500,000 | 6,000,000 | +2,000,000 | 양호 |

**환자당 월 100만 원이 손익분기점입니다.**

참고로 현재 시장의 공동간병은 하루 9천~3만 원 수준(월 27~90만 원)입니다. **현행 공동간병 단가 그대로 급여화되면 직접고용은 적자입니다.**

> ### 🔴 최우선 확인 사항
> **급여화 시범사업의 간병 수가(환자 1인당, 간병인 배치비율별)를 확인하세요.**
> 이 값이 100만 원 미만이면 요양병원 공동간병 채널은 **직접고용이 아니라 위탁으로 가야** 합니다.
> 사업 구조 전체가 여기에 달려 있습니다.

### 2.4 요양보호사 배치 (외국인 파이프라인)

D-10 세그먼트 1인 기준입니다.

**원가**

| 항목 | 금액 |
|---|---|
| 모집·설명회 (CAC) | 400,000 |
| 선발·클리어런스 6종 | 200,000 |
| 교육비 지원분 (50%) | 350,000 |
| 케어 코디네이터 6개월 (인당 배분) | 900,000 |

| **총 원가** | **약 2,900,000원/인** |

**수익 시나리오**

| 모델 | 수익 | 회수 |
|---|---|---|
| 성공보수 1회 (월급 1개월분) | 2,500,000 | **−400,000 (적자)** |

> **핵심 발견: 파이프라인 원가를 성공보수 한 번으로 회수할 수 없습니다.**
> 외국인 인력 파이프라인은 **배치 후 지속 수익 구조(직접고용 또는 구독)와 반드시 결합**되어야 합니다.
> 단순 소개 모델로는 만들수록 손해입니다.

이것이 CARELINK가 소개소가 아니라 운영사여야 하는 **재무적 근거**입니다.


## 4. 민감도 분석

사업의 생사를 가르는 순서입니다.

| 변수 | 기준 | 악화 시 | 영향 |
|---|---|---|---|
| **① 급여화 공동간병 수가** | 환자당 월 100만 | 80만 | **채널 자체가 적자** |
| **② 가동률** | 90% | 75% | 원가 +33%, 마진 소멸 |
| **③ 이직률** | 연 30% | 연 50% | 재확보 원가 연 2.9억 증가 |
| ④ 인건비 상승 | 연 5% | 연 10% | 단가 인상 협상 필요 |
| ⑤ 파이프라인 이탈률 | 교육 17% | 30% | 인당 원가 +80만 |
| ⑥ CAC | 40만 | 80만 | 인당 원가 +40만 |

**①과 ②가 압도적입니다.** ③~⑥은 관리로 흡수 가능하지만, ①은 외생 변수이고 ②는 채널 포트폴리오 설계 문제입니다.

### 4.1 이직률이 왜 그렇게 큰가

```
인당 확보 원가          2,900,000원 (외국인) / 800,000원 (국내)
연 이직률 30% · 200명 → 60명 재확보 → 연 1.7억
연 이직률 50% · 200명 → 100명 재확보 → 연 2.9억
                                    ─────────────
                              차이     연 1.2억 = 고정비 1.5개월분
```

**근속 관리가 마케팅보다 값싼 성장 수단입니다.** 이것이 플랫폼에 근속 데이터를 쌓는 재무적 이유입니다.

## 5. 채널 포트폴리오 목표

가동률 90%를 유지하면서 마진을 확보하는 조합입니다.

| 채널 | 인력 비중 | 고용 모델 | 역할 |
|---|---|---|---|
| 요양병원 1:1·공동간병 | 45% | 직접고용 | 안정 매출·가동률 기반 |
| 보험 간병 | 30% | 위탁 | **가동률 밸런싱** · 현금흐름 |
| 요양시설 (요양보호사) | 20% | 직접고용 | 외국인 파이프라인 배치처 |
| 재가·주간 (결혼이민자) | 5% | 중개 | 시간제 수요 흡수 |

**보험 채널 30%가 밸런서입니다.** 마진은 얇지만 단기·변동 수요를 흡수해 직접고용 인력의 공백을 메웁니다. 이게 없으면 가동률이 80% 아래로 떨어지고 전체가 무너집니다.

## 6. 측정 체계

플랫폼에서 자동 산출되어야 하는 값입니다.

| 지표 | 산식 | 원천 |
|---|---|---|
| 인당 월 마진 | (billing_lines − payout_lines) ÷ 배치 인원 | `engagement` |
| **가동률** | 배치일수 ÷ 고용일수 | `work_records` / `engagements` |
| 채널별 CAC | 캠페인 비용 ÷ 배치 성공 인원 | `recruiting_campaigns` |
| 인당 LTV | 월 마진 × 평균 근속 개월 | `engagements` |
| **LTV / CAC** | 목표 3배 이상 | |
| 이직률 | 종료 engagement ÷ 평균 재직 인원 | `engagements` |
| 기관별 수익성 | billing − 배치 원가 | `billing_lines` |

**가동률이 대시보드 최상단에 있어야 합니다.** 이 사업에서 가동률은 운영 지표가 아니라 생존 지표입니다.
