## About the Design Files
번들에 든 `.dc.html` 파일은 **HTML로 만든 디자인 레퍼런스**입니다. 그대로 제품에 올리는 코드가 아니라,
의도한 레이아웃·색·타이포·상태 표현을 보여주는 시안입니다. 각 파일은 브라우저로 바로 열립니다 (같은 폴더의 `support.js` 필요).

구현 과제는 이 시안을 **대상 코드베이스의 기존 환경에 다시 만드는 것**입니다.
- Candidate / Caregiver App → Flutter
- Patient / Organization / Admin → Next.js (`packages/ui` 공용 컴포넌트)
환경이 아직 없다면 위 표의 플랫폼을 기준으로 프로젝트를 세우고 구현하세요. HTML/인라인 스타일을 그대로 옮기지 마세요.

## Fidelity
**High-fidelity.** 색·타이포·간격·상태 배지·터치 타깃까지 확정값입니다. 픽셀 단위로 재현하되,
그리는 방식은 코드베이스의 기존 컴포넌트·토큰 시스템을 사용하세요. 데이터는 모두 예시 값입니다.

프레임 규격
- FIELD(모바일): 402 × 1096 — 1096은 러시아어 최장 카피가 들어가도 콘텐츠가 잘리지 않는 높이 기준입니다. 실제 기기에서는 스크롤 뷰입니다.
- DESK(웹): 1440 × 900 — 사이드바 고정, 본문 영역만 스크롤.

## Design Tokens

### 색 (문서 §5.1에서 확정, 이번 시안에서 갱신됨)
문서 원본은 임상적 저채도 팔레트(signal `#1F6F5C`)였습니다. 사용자 요청("토스처럼 밝고 직관적")에 따라
**액션색을 밝은 블루로 교체**하고, 초록은 '통과/완료' 의미색으로만 남겼습니다. 토큰 표를 이 값으로 갱신해야 합니다.

## 신규 컴포넌트 5종 (문서 §7 — 먼저 확정할 것)

### 1. ExpiryCountdown
`D-42` 형태. mono 17~20px / 700. 컨테이너는 flag tint + 달력 아이콘 + 항목명 + D-day 한 줄.
임계값: D-90 이상 `signal` / D-89~D-31 `flag` / D-30 이하 `alert`. 날짜 원문은 툴팁·상세에만.
사용처: SCR-101, 104, 105, 110, 203, 204, 502, 508.

### 2. ClearanceMatrix
서류 5~7종의 상태 집합. 두 가지 표현을 같은 데이터로 렌더합니다.
- FIELD(SCR-105): 항목별 카드 리스트 — 아이콘 타일 + 항목명 + 상태 pill(승인/검토/임박/미제출) + 조치 버튼.
- DESK(SCR-203, 502): 16×16 radius 4 사각형 5개를 가로로 — 순서 고정 **여권 · 자격증 · 범죄경력 · 건강검진 · 체류자격**, 색은 `#00703A` 승인 / `#C77700` 검토 / `#C7302A` 만료·미제출 / `#8B95A1` 미해당. 범례를 표 하단에 항상 노출.
- SCR-204는 항목·만료일·상태 3열 표 형태.

### 3. MatchReasonList
점수 단독 노출 금지. 항목마다 아이콘 + 사유 + 가중치(`+30`, `-8`)를 함께.
충족은 signal 원형 체크, 부족은 flag 원형 시계, 차단은 카드 하단에 alert 블록으로 분리하고
**차단 사유 문장과 후속 조치(발송 이력·날짜)를 반드시 포함**합니다. 사용처: SCR-108(모바일), 204, 504.

### 4. FunnelTable
단계 / 인원 / 전환 바 / 체류일 / 상태 5열. 전환 바는 첫 단계를 100%로 한 상대 폭.
체류일(각 단계 평균 소요)이 기준 초과면 상태 열에 `지체`(flag), 차단 건수가 있으면 `차단 n`(alert).
마지막 행(배치 완료)은 `#F9FAFB` 배경 + signal 수치. 사용처: SCR-201, 501(공급 파이프라인 변형).

### 5. LocaleSwitcher
앱바: 48×(가변) 필, 지구 아이콘 + `KO` mono 14px. 설정(SCR-110): 4개 동등 버튼(한국어/Việt/Рус/Eng) 52px.
전환 시 앱 전체 즉시 리렌더. ko/vi/ru/en 4개 언어, FIELD는 4개 전부 · DESK는 ko 전용.

- **503 기관 관리** — KPI 5칩 + 표 7행. 사건 누적 기관은 `신규 배정 정지`(alert) 상태로.
- **508 고용 · 계약** — KPI 5칩 + 조치 필요 계약 표. 만료 D-30 이내 alert, 서명 대기 경과일 flag, 서류 부족 시 `발송 보류`.
- **509 품질 · 안전** — KPI 5칩, 사건 유형별 추이(건수·분포 바·재발·평균 종결), 점검 필요 기관 5곳.
- **510 파트너 · 채널** — KPI 5칩 + 표 6행. 배치율 바 + 반송률. 반송률 30%+는 `품질 경고`.

- **507 산업 · 트랙** — 좌 280px 산업 3개(V1/V2/V3), 우 트랙 표 5행(필수 자격·한국어·급여 밴드·후보·배치) + 승급 경로.

## Interactions & Behavior
- **상태는 색 + 아이콘 + 텍스트 3중.** 색만으로, 또는 아이콘만으로 상태를 전달하는 구현은 반려 대상입니다 (문서 §4.2).
- **차단은 항상 사유와 함께.** 매칭 제외·배정 차단·발송 보류 어디서든 사유 문장을 같은 화면에 노출합니다.
- **점수는 항상 근거와 함께.** 매치 점수 단독 표시 금지.
- **한 화면 한 과업 (FIELD).** `next_action`은 화면당 1개. 목록으로 나열하지 않습니다.
- **만료는 카운트다운.** 날짜만 노출하지 않습니다.
- **최소 노출.** 권한 밖 필드는 비활성화가 아니라 미렌더링.
- **오프라인 (Caregiver).** 근무 기록은 로컬 큐 → 재동기화. 오프라인 상태를 화면에 표시하고, 저장 버튼은 오프라인에서도 활성.
- **입력 최소화 (FIELD/Patient).** 자유 입력 대신 선택지. 키보드를 띄우는 순간 이탈합니다.
- **DESK 일괄 처리.** 표는 정렬·필터 가능, 다중 선택 시 일괄 처리 바가 표 위에 나타납니다. 단축키 지원 권장.
- hover: DESK 행 `#F9FAFB`, 버튼은 action-strong → `#1B4FCC`. FIELD 버튼 press 시 tint.
- 전환: 200ms ease-out 이내. 과한 모션 없음.
