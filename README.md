## 4. 디자인 시안 ↔ 도메인 규칙 충돌 — 구현 전 판정 필요

시안을 그대로 구현하면 `CLAUDE.md` §6 금지 사항에 걸리는 지점입니다.
**시안이 틀렸는지, 규칙에 예외가 필요한지 사람이 정해야 합니다.**

| # | 지점 | 시안 | 충돌하는 규칙 |
|---|---|---|---|
| **C1** | SCR-303 `필요한 도움` 칩, SCR-401 `오늘 확인할 것`, SCR-403 `주의사항`, SCR-404 `근무 기록` 체크항목, SCR-506 | **"투약 확인"** 이 정형 선택 항목으로 존재 | **`docs/07` §3.3이 확정**: 카탈로그에서 투약·주사·석션·욕창 처치·혈당 측정·관장은 "**항목 자체가 존재하지 않음**". `restricted_act_keywords` 시드에도 `투약`이 있어 자유 입력이면 `OPS_REVIEW` 트리거 |
| **C2** | SCR-303 `돌봄 시간` | **`24시간 상주`가 기본 선택 상태**로 조판됨 | §5.12 / `docs/12` D7: 기본값은 `H8_3SHIFT`. `H24_LIVE_IN`은 `requires_approval = true` |
| **C3** | SCR-304 간병사 카드 | `경력 3년 2개월 · **베트남**` — 국적 노출 (3명 전부) | `docs/07` §2.2는 "**기관** 노출 화면에 국적 표시 금지"라 문언상 환자·보호자 화면을 직접 다루지 않습니다. 다만 D6·§5.10의 취지와는 어긋납니다 — **회색 영역, 판단 필요** |
| **C4** | SCR-401·402·403 | 간병사에게 **환자 실명**(`김영수 어르신`) + 나이·성별 노출 | `docs/11` §3.2: 간병사에게는 병실·필요 지원·주의사항만. 실명 ❌ |

**C1·C2·C4는 시안이 틀린 것으로 정리됩니다** — `docs/07` §3.3(카탈로그 제외), §3.6(H24 비권장),
`docs/11` §3.2(환자 실명 비노출)가 각각 명시적으로 반대편에 있습니다.
**C3만 판단이 필요합니다.** 규정이 금지하는 것은 '기관' 노출 화면인데 SCR-304는 환자·보호자 화면입니다.

C1이 가장 무겁습니다. 5개 화면에 걸쳐 있고, 시안대로 만들면 의료행위를 플랫폼이
정형 항목으로 승인하는 형태가 됩니다.

### 4-2. `SCREENS` ↔ 디자인 시안 불일치

같은 화면 ID인데 두 소스가 다른 것을 말합니다. `CLAUDE.md` §0상 `SCREENS`가 사양의
단일 출처지만, 시안이 더 나중에 나왔고 `design/README`가 "확정값"이라고 선언합니다.
**어느 쪽이 최신인지 화면별로 확인이 필요합니다.**

| # | 화면 | `SCREENS` | 디자인 시안 |
|---|---|---|---|
| **S1** | SCR-002 로그인 | 이메일/비밀번호 + OTP 병행. `INVALID_CREDENTIAL`·`LOCKED(5회)` 상태 보유 | **비밀번호 없음.** 휴대폰 번호 + 인증 문자만 |
| **S2** | SCR-003 역할 선택 | 역할 **4개** (Candidate · Caregiver · 환자/보호자 · **기관**) | 역할 **3개.** 기관 카드 없음 |
| **S3** | SCR-101 홈 | 진행률 **% 미터** ("8단계 중 5단계") | 진행 단계 **점 5개** — `지원·계약·서류·비자·입국` |

**S2는 `docs/02` §5.1로 기웁니다.** 역할 8종에 `ORG_MEMBER`가 있고 SCR-003의 `next`에
`SCR-201`(기관 대시보드)이 들어 있습니다. 시안에 기관 카드를 추가하는 방향이 맞아 보입니다.

**S3이 가장 무겁습니다.** `docs/02` §6.1과 `SCREENS` SCR-102는 여정을 **9단계**
(`APPLIED → PROFILE_REGISTERED → DOC_REVIEW → TRAINING → READY → MATCHED →
INTERVIEW → PLACED → ACTIVE`)로 정의해 서로 일치합니다. 그런데 시안 SCR-101의 5점 스테퍼는
`지원·계약·서류·비자·입국`으로 **이 9단계와 대응 관계가 아예 없습니다** — 커리어 여정이 아니라
해외 입국 절차를 그린 것입니다. `candidate_journey_steps`에 무엇을 적재할지가 걸려 있으니
둘 중 하나를 고르는 게 아니라 **두 축을 별도로 둘지 판단**이 필요합니다.

**전수 대조는 아직 하지 않았습니다.** 위 3건은 공통 진입 + SCR-101을 확인하며 나온 것이고,
나머지 37개 화면은 스캐폴딩 직전에 일괄 대조할 예정입니다.
